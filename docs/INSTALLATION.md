# Install Temper & Tang

Use Minecraft 1.21.1, Java 21, and one loader: Fabric or NeoForge. Put the matching Temper & Tang build in `mods` on the server and each client.

| Library | Tested build |
| --- | --- |
| Diegesis | 1.0.0-beta.19, matching your loader |
| Fzzy Config | 0.7.7+1.21 on Fabric; 0.7.7+fix1+1.21+neoforge on NeoForge |
| Fabric API | 0.116.18 for 1.21.1, Fabric only |
| Fabric Language Kotlin | 1.14.2+kotlin.2.4.21, Fabric only |
| Kotlin for Forge | 5.13.0, NeoForge only |

These are separate dependencies, not bundled copies. Recipe viewers and additional equipment integrations are optional. Use the same workshop version and server settings across the group.

Tin and silver ore generate in new Overworld chunks. Existing chunks keep their terrain. The [workshop guide](THERMAL_WORKSHOP.md) walks through the first metal and station recipes.
