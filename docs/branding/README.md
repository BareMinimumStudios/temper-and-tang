# Temper & Tang branding

The banner combines a crop of the in-game shaping capture in `docs/images/shaping.png` with a typeset wordmark and the project emblem. The emblem is a 32 × 32 pixel drawing of an anvil and hot workpiece, enlarged with nearest-neighbor scaling. It uses ivory and copper against charcoal.

- `banner.png` is the 1800 × 600 storefront and README header.
- `icon.png` is the 512 × 512 project icon. The same image is packaged as `assets/temperandtang/icon.png`.

The replacement art was assembled with a drawing script. It uses no image-generation output or pixels from the previous banner or icon.
