# Temper & Tang branding

`banner.png` is the wide project header. `icon.png` is the square emblem, also packaged as `assets/temperandtang/icon.png`.

The emblem uses rounded outlines: a warm ivory anvil and a muted copper hammer on charcoal. The banner pairs it with the medieval Temper & Tang wordmark. Keep the artwork flat and the outlines clear; avoid glow, metallic texture and extra ornaments.

Keep the banner proportions intact. Use the square icon in project lists and the mod menu. Gameplay images in `docs/images` are actual captures.
